Tu vas implémenter dans EffectForge AI un système de 
chirurgie visuelle par zones pour les signatures vivantes.
Chaque zone de la signature possède sa propre bibliothèque 
d'effets codifiée, ses propres règles de combinaison, 
et l'IA sélectionne intelligemment depuis cette liste 
structurée pour garantir un rendu God Tier cohérent 
et jamais chaotique.

═══════════════════════════════════════════════════════
PHILOSOPHIE DU SYSTÈME
═══════════════════════════════════════════════════════

Chaque zone de la signature est un univers indépendant.
Les effets sont pensés spécifiquement pour leur zone.
L'IA ne mélange jamais des effets incompatibles.
Le résultat final est une symphonie visuelle cohérente
où chaque zone joue sa partition sans jamais couvrir
les autres.

Les 7 zones chirurgicales :
1. LOGO        — La pièce maîtresse 3D vivante
2. NOM         — L'identité typographique
3. TITRE       — Le positionnement subtil
4. CONTACT     — L'information en cascade
5. SÉPARATEUR  — Le flux d'énergie vertical
6. FOND        — L'univers atmosphérique
7. CTA         — L'invitation magnétique

═══════════════════════════════════════════════════════
PARTIE 1 — BIBLIOTHÈQUE D'EFFETS PAR ZONE
═══════════════════════════════════════════════════════

Créer server/data/zone-effects-library.json

Ce fichier JSON est la source de vérité absolue
que l'IA consulte pour sélectionner les effets.
Il contient pour chaque zone tous les effets
disponibles avec leurs règles de compatibilité.

PARTIE 2 — MODULE IA DE SÉLECTION PAR ZONE
═══════════════════════════════════════════════════════

Créer server/services/zone-effect-selector.ts

Ce module reçoit le brief créatif du Cerveau 1
et le scénario narratif du Cerveau 2, puis
sélectionne les effets appropriés depuis
zone-effects-library.json pour chaque variation.

Il fournit à Gemini Flash (Cerveau 3) une liste
pré-filtrée et validée d'effets compatibles
pour chaque zone — Gemini ne choisit plus 
dans 847 effets mais dans une liste courte
et cohérente de 3 à 5 options par zone.

function selectCandidatesForZone(
  zone: string,
  secteur: string,
  tonEmotionnel: string,
  intensiteMouvement: string,
  variationContext: string
): EffetCandidat[] {

  1. Charger la zone depuis zone-effects-library.json

  2. Filtrer par secteur compatible
     Exclure les effets avec secteur incompatible

  3. Filtrer par intensité mouvement :
     'minimal' → intensite.defaut < 0.2 uniquement
     'subtil'  → intensite.defaut < 0.4
     'expressif' → tous
     'dramatique' → intensite.max > 0.5 préféré

  4. Filtrer par contexte de variation :
     Variation A → effets stables et rassurants
     Variation B → effets précis et dynamiques
     Variation C → effets profonds et atmosphériques
     Variation D → effets puissants et mémorables

  5. Retourner max 4 candidats par zone
     avec leur score de compatibilité

  6. Valider les incompatibilités entre zones :
     Si LOGO_ORBITAL_PARTICLES est sélectionné
     → FOND_STELLAR_DRIFT intensité réduite de 50%
     pour éviter la surcharge particulaire

  7. Retourner le JSON final des candidats
     pour soumission à Gemini Flash
}

PARTIE 4 — GÉNÉRATEUR SVG PAR ZONE
═══════════════════════════════════════════════════════

Créer server/services/zone-svg-renderer.ts

Pour chaque effet sélectionné par Gemini,
ce module génère le code SVG/CSS exact
correspondant à l'effet, à l'intensité
et aux couleurs définies.

Chaque effet a sa fonction de génération :

function renderEffect(
  effectId: string,
  zone: ZoneConfig,
  params: EffectParams,
  variationIndex: 'A' | 'B' | 'C' | 'D',
  delayOffset: number
): SVGEffectCode {

  switch(effectId) {

    case 'LOGO_3D_FLOAT':
      return generateLogo3DFloat(zone, params, delayOffset)

    case 'LOGO_HALO_PULSE':
      return generateLogoHaloPulse(zone, params, delayOffset)

    case 'NOM_SHIMMER_GOLD':
      return generateNomShimmerGold(zone, params, delayOffset)

    case 'SEP_ENERGY_FLOW':
      return generateSepEnergyFlow(zone, params, delayOffset)

    case 'FOND_STELLAR_DRIFT':
      return generateFondStellarDrift(zone, params, delayOffset)

    case 'CTA_GRAVITY_PULSE':
      return generateCtaGravityPulse(zone, params, delayOffset)

    // ... un cas pour chaque effet de la bibliothèque
  }
}

Chaque fonction génère :
- Les keyframes CSS spécifiques à la variation
- Les éléments SVG nécessaires (cercles, rects, paths)
- Les delays calculés pour la variation (A=0s B=62s C=122s D=182s)
- Les durées respectant le cycle total de 240s

PARTIE 5 — VALIDATION FINALE ANTI-CHAOS
═══════════════════════════════════════════════════════

Créer server/services/harmony-validator.ts

Avant de générer le SVG final, ce module
vérifie que la combinaison d'effets sélectionnés
respecte les règles d'harmonie globale.

Règles de validation :

RÈGLE 1 — Densité visuelle
Compter le nombre total d'éléments animés.
Si > 12 éléments simultanés → réduire
les effets de fond en intensité de 40%.

RÈGLE 2 — Hiérarchie visuelle
L'intensité doit toujours respecter :
Logo > Nom > CTA > Séparateur > Fond > Titre > Contact
Si une zone inférieure a une intensité supérieure
→ la recalibrer automatiquement.

RÈGLE 3 — Cohérence de vitesse
Si le logo est en mode 'slow' →
le fond doit être 'slow' aussi.
Les vitesses disparates créent du chaos.
Harmoniser toutes les vitesses autour
de la vitesse du logo.

RÈGLE 4 — Compatibilité palette
Toutes les couleurs des effets doivent
appartenir à la palette client ou en être
des dérivés (version plus claire / plus sombre).
Rejeter toute couleur hors palette.

RÈGLE 5 — Test lisibilité
Simuler le contraste entre les effets animés
et le texte du nom et du titre.
Si contraste < 4.5:1 → réduire l'intensité
du fond et du séparateur jusqu'à conformité.

Si toutes les règles passent → 
retourner { valid: true, config: finalConfig }

Si une règle échoue →
corriger automatiquement et retourner
{ valid: true, corrections: [...], config: fixedConfig }
