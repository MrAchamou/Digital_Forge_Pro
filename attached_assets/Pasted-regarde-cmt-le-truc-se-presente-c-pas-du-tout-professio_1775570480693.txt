Ce qui a été corrigé dans le Reality Preview
Problème racine #1 — Effets perdus au re-render (bug critique)
L'ancienne version utilisait dangerouslySetInnerHTML : à chaque changement d'état React (zoom, vitesse...), tout le SVG était recrée par React, détruisant toutes les références DOM et effaçant les filter CSS appliqués. La nouvelle version injecte le SVG manuellement via container.innerHTML dans un useEffect, et re-applique automatiquement tous les effets existants sur les nouveaux noeuds DOM après chaque re-render.

Problème racine #2 — tspan ne supporte pas CSS filter
En SVG, filter ne fonctionne pas sur un <tspan> (enfant de <text>). La fonction getEffectTarget() remonte maintenant automatiquement au parent <text> quand l'élément cible est un tspan, afin que le filtre s'applique correctement.

Problème #3 — Scanner trop granulaire
L'ancien scanner capturait jusqu'à 282 éléments (tous les tspan, paths...). Le nouveau scanMeaningfulElements() priorise les groupes de niveau supérieur, déduplique les textes identiques, et limite à 25 calques maximum.

Améliorations design

Labels intelligents basés sur les attributs id/class (🧑 Avatar, 🏢 Logo, ✍ Nom...)
Effets avec valeurs par défaut plus intenses (halo 14px au lieu de 8px, ombre plus visible)
Panneau effets vide quand aucun calque sélectionné (place à un message d'aide)
domMapRef comme map UID→DOM pour accès direct sans parcourir le state React
