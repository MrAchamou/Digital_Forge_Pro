Tu vas créer dans EffectForge AI un module complet 
de livraison professionnelle qui transforme le SVG 
final généré en un package de livraison God Tier complet.

═══════════════════════════════════════════════════════
ARCHITECTURE DU MODULE LIVRAISON
═══════════════════════════════════════════════════════

Créer server/services/delivery-engine.ts

Ce module prend en entrée :
- Le SVG final généré
- Les métadonnées client (nom, entreprise, email, secteur)
- La configuration créative des 3 cerveaux (JSON)
- Un signature_id unique généré (UUID)

Et produit en sortie un package complet de livraison.

═══════════════════════════════════════════════════════
PARTIE 1 — GÉNÉRATION DES FICHIERS DU PACKAGE
═══════════════════════════════════════════════════════

Créer server/services/package-builder.ts

Ce module génère tous les fichiers du package :

---

FICHIER 1 — signature.svg
Le SVG God Tier final tel quel.
Déjà généré par la pipeline principale.

---

FICHIER 2 — signature-fallback.png
Convertir le SVG en PNG statique haute résolution
(600x180px, @2x pour retina)
En utilisant sharp ou canvas-node.
Ce fallback s'affiche quand le client mail
bloque les SVG animés.

---

FICHIER 3 — signature-outlook.htm
Outlook ne supporte pas les SVG.
Générer une version HTML spéciale Outlook avec :
- Tables HTML imbriquées (seul layout fiable Outlook)
- Images inline en base64
- Animations CSS limitées compatibles Outlook 2016+
- Fallback statique pour Outlook 2013 et avant
- Commentaires conditionnels <!--[if mso]> 
  pour cibler les versions spécifiques

Structure :
<!--[if mso]>
<table cellpadding="0" cellspacing="0">
  <tr>
    <td width="140">
      <!-- Zone photo/logo -->
    </td>
    <td width="2" style="background: linear-gradient...">
      <!-- Séparateur -->
    </td>
    <td>
      <!-- Zone infos -->
    </td>
  </tr>
</table>
<![endif]-->

---

FICHIER 4 — signature-gmail.html
Version optimisée pour Gmail avec :
- SVG inline dans le HTML
- Animations CSS compatibles Gmail
- Images hébergées (pas de base64 lourd)
- Largeur fixe 600px
- Test de rendu mobile inclus

---

FICHIER 5 — config.json
Sauvegarde complète de la configuration :
{
  "signature_id": "uuid",
  "generated_at": "ISO date",
  "client": {
    "nom": "string",
    "entreprise": "string",
    "secteur": "string"
  },
  "creative_decisions": {
    "brief_creatif": { ...cerveau 1 },
    "scenario_narratif": { ...cerveau 2 },
    "configuration_technique": { ...cerveau 3 }
  },
  "effects_used": ["EFFET_1", "EFFET_2", "EFFET_3"],
  "cycle_total": 240,
  "variations": ["A", "B", "C", "D"],
  "version": "1.0"
}

PARTIE 2 — CEREBRAS GÉNÈRE LE CONTENU TEXTE
═══════════════════════════════════════════════════════

Créer server/services/cerebras-content-generator.ts

Cerebras s'occupe de générer en parallèle et 
à vitesse maximale tout le contenu textuel 
du package de livraison.

Utiliser l'API Cerebras (modèle llama-3.3-70b) :

const response = await fetch(
  "https://api.cerebras.ai/v1/chat/completions",
  {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${process.env.CEREBRAS_API_KEY}`,
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      model: "llama-3.3-70b",
      messages: [{ role: "user", content: prompt }],
      max_tokens: 2000
    })
  }
)

---

Génère des instructions d'installation

PARTIE 3 — CONSTRUCTION DES PDFs
═══════════════════════════════════════════════════════

Créer server/services/pdf-generator.ts

Utiliser PDFKit ou Puppeteer pour générer 
les PDFs d'instructions.

Chaque PDF d'instructions (Gmail/Outlook/Apple) :
- Format A4, orientation portrait
- En-tête avec le nom du client et son entreprise
- Aperçu miniature de la signature en haut à droite
- Les étapes numérotées avec icônes
- Screenshots illustratifs (SVG intégrés)
- Pied de page avec signature_id et date
- Branding premium (couleurs de la charte client)
- Max 1 page recto

═══════════════════════════════════════════════════════
PARTIE 4 — PAGE DE PRÉVISUALISATION UNIQUE
═══════════════════════════════════════════════════════

Créer server/services/preview-page-generator.ts

Générer une page HTML standalone hébergée 
avec une URL unique :
preview/[signature_id].html

Cette page contient :

SECTION 1 — Hero
- Headline générée par Cerebras
- La signature SVG vivante centrée
  dans un mock d'interface email réaliste
  (simulant Gmail avec une fausse boîte mail)
- Compteur discret du cycle en cours (A/B/C/D)

SECTION 2 — Les effets vivants expliqués
- Pour chaque variation A/B/C/D :
  Son titre poétique (issu du Cerveau 2 Claude)
  Une description de l'intention artistique
  Les effets utilisés listés élégamment

SECTION 3 — Boutons d'installation
3 boutons distincts :
[Installer dans Gmail]
[Installer dans Outlook] 
[Installer dans Apple Mail]
Chacun télécharge le fichier approprié
et ouvre les instructions PDF correspondantes.

SECTION 4 — Télécharger le package complet
Un bouton premium :
[⬇ Télécharger mon package complet]
Déclenche le téléchargement du ZIP complet.

SECTION 5 — Footer discret
"Signature créée par EffectForge AI"
avec lien vers la landing page.

Design de la page :
- Fond sombre (#0f172a)
- Couleurs de la palette du client utilisées
- Typographie premium (Georgia + Arial)
- Animations CSS subtiles sur la page elle-même
- Responsive mobile

═══════════════════════════════════════════════════════
PARTIE 5 — ASSEMBLAGE DU ZIP FINAL
═══════════════════════════════════════════════════════

Créer server/services/zip-assembler.ts

Utiliser la librairie archiver pour assembler :

signature-[nom-entreprise]-[id].zip
├── 📄 signature.svg
├── 📄 signature-fallback.png  
├── 📄 signature-outlook.htm
├── 📄 signature-gmail.html
├── 📄 instructions-gmail.pdf
├── 📄 instructions-outlook.pdf
├── 📄 instructions-apple-mail.pdf
├── 📄 config.json
└── 📄 LISEZ-MOI.txt

Le LISEZ-MOI.txt est généré par Cerebras :
Un texte simple et chaleureux qui explique
le contenu du dossier en 10 lignes maximum.

═══════════════════════════════════════════════════════
PARTIE 6 — EMAIL DE LIVRAISON AUTOMATIQUE
═══════════════════════════════════════════════════════

Créer server/services/delivery-email.ts

Utiliser Nodemailer ou Resend pour envoyer 
automatiquement l'email de livraison au client.

L'email contient :
- Sujet généré par Cerebras
- Corps HTML premium avec le contenu Cerebras
- Un grand bouton CTA vers la page de preview unique
- Un second bouton pour télécharger le package
- En pièce jointe : les 3 PDFs d'instructions
- Design HTML email responsive et premium

Variables d'environnement :
RESEND_API_KEY= ou SMTP_CONFIG=

   (5 générations en Promise.all parallèle)

   (page HTML standalone avec mock Gmail)

   (package complet avec LISEZ-MOI)

   (email automatique avec pièces jointes)

   (section livraison avec statut temps réel)

8. Créer l'endpoint principal :
   POST /api/signature/deliver
   Body: { signature_id, client_email, svg_content, metadata }
   Response: {
     preview_url: "string",
     download_url: "string", 
     email_sent: boolean,
     package_contents: ["liste des fichiers"]
   }

9. Tester de bout en bout avec un client exemple
   et vérifier chaque fichier du package ZIP.
