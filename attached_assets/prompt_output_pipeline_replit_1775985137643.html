Vision du système — lire en premier
# CE QUE TU DOIS CONSTRUIRE Un pipeline de génération automatique d'output premium pour une agence de signatures email vivantes. L'opérateur entre les données d'un client dans un formulaire. Le système génère automatiquement et simultanément 5 fichiers qui constituent le livrable complet au client. RÈGLE ABSOLUE : Ces 5 fichiers forment un système solidaire. Ils partagent les mêmes données source. Ils se génèrent ensemble, en une seule action. Jamais séparément, jamais manuellement.
Les 5 fichiers du livrable — définition exacte
FICHIER 1 — signature-[nom-client].gif Le GIF animé final. 600×220px. Contient : logo animé + infos + CTA + bannière dynamique. Généré depuis le SVG template avec les variables du client. Encodé avec qualité maximale + Floyd-Steinberg dithering. Hébergé sur Cloudinary → URL CDN permanente. FICHIER 2 — demo-mail-[nom-client].html Interface Gmail simulée ultra-réaliste. Affiche un vrai mail professionnel avec : → Expéditeur = nom + email du client → Objet = adapté au secteur détecté automatiquement → Corps = message professionnel crédible (secteur-aware) → Signature = le GIF du fichier 1 intégré en live Ce fichier est hébergé et accessible via URL publique. C'est le lien qu'on envoie au prospect pour le convaincre. FICHIER 3 — guide-installation-[nom-client].pdf PDF 7 pages généré automatiquement. Page de couverture personnalisée avec nom + logo du client. 1 page par client mail : Gmail, Outlook, Apple Mail, Yahoo, Thunderbird, Mobile, Méthode HTML universelle. Captures annotées avec flèches + étapes numérotées. Lien URL personnel du client sur chaque page. FICHIER 4 — copier-coller-[nom-client].html Page ultra-simple, une seule fonction : 3 boutons — "Copier pour Gmail", "Copier pour Outlook", "Copier code HTML universel". Chaque bouton copie le bon code dans le presse-papier. Design épuré, une seule couleur, zéro distraction. FICHIER 5 — livrable-[nom-client].zip Archive qui contient les fichiers 1 à 4. + fichier MON-LIEN-PERMANENT.txt (juste l'URL Cloudinary) Téléchargeable en un clic depuis le dashboard opérateur.
Le formulaire opérateur — données d'entrée
# SECTION 1 — Identité client prénom : string (obligatoire) nom : string (obligatoire) titre : string (obligatoire — ex: "Médecin Généraliste") entreprise : string (optionnel) secteur : select (médical / juridique / immobilier / finance / tech / créatif / autre) # SECTION 2 — Coordonnées téléphone : string email : string site_web : string (si fourni → scraping automatique) ville : string pays : string # SECTION 3 — Visuel logo_url : upload ou URL (optionnel) couleur_1 : color picker (extraite du site si scraping) couleur_2 : color picker effet_animation : select (liste des 55 effets disponibles) # SECTION 4 — Bannière dynamique banniere_texte : string (ex: "Consultation en ligne disponible") banniere_sous_texte : string (ex: "Disponible jusqu'au 30 avril") banniere_cta : string (ex: "Prendre rendez-vous") banniere_url : string (URL du lien CTA) # SECTION 5 — Mail de démo destinataire_nom : string (ex: "Marie Dupont" — un faux patient/client) destinataire_email : string (ex: "marie.dupont@exemple.com") objet_mail : string (auto-généré selon secteur, modifiable) corps_mail : textarea (auto-généré selon secteur, modifiable)
Le scraping automatique — quand site_web est fourni
# Si l'opérateur entre une URL de site web, # le système scrape automatiquement : → Couleurs dominantes du site (palette hex extraite) → Logo existant (si trouvable) → Numéro de téléphone → Adresse email de contact → Adresse physique / ville → Description de l'activité (pour auto-générer corps mail) → Nom exact de l'entreprise Ces données pré-remplissent le formulaire. L'opérateur valide, corrige si besoin, puis génère. # Stack scraping : puppeteer ou playwright → rendu JS des sites modernes cheerio → parsing HTML color-thief → extraction palette couleurs sharp → traitement image logo
La génération du mail de démo — logique exacte
# demo-mail-[nom].html doit être une interface # Gmail simulée PARFAITE — pas un wireframe. Structure HTML du mail simulé : ┌─ Barre Gmail simulée (gris clair, logo G fictif) │ ├─ En-tête du mail │ ├─ Avatar initiales du client (couleur_1) │ ├─ Nom expéditeur = [prénom nom du client] │ ├─ Email expéditeur = [email du client] │ ├─ Date = date du jour formatée │ ├─ Objet = généré selon secteur │ └─ À : [destinataire_nom] [destinataire_email] │ ├─ Corps du mail │ └─ Texte professionnel crédible, secteur-aware │ Médical → "Suite à votre consultation..." │ Juridique → "Suite à notre entretien concernant..." │ Immobilier→ "Suite à la visite du bien situé..." │ Finance → "Suite à notre point patrimonial..." │ (généré automatiquement, modifiable dans formulaire) │ └─ Signature └─ [GIF animé] affiché en pleine largeur (600px) src = URL Cloudinary du fichier 1 CRITIQUE : Le HTML du mail de démo est hébergé à une URL publique. Format : https://[domaine]/demo/[token-unique] Ce lien est ce qu'on envoie au prospect. Il doit s'afficher parfaitement sur mobile ET desktop.

Le pipeline de génération — ordre d'exécution
ÉTAPE 1 — Validation des données (1s) Vérifier que tous les champs obligatoires sont remplis. Si site_web fourni → lancer le scraping en parallèle. ÉTAPE 2 — Génération du SVG personnalisé (2s) Charger le template SVG master. Remplacer toutes les variables : {{PRENOM_NOM}}, {{TITRE}}, {{ENTREPRISE}} {{TEL}}, {{EMAIL}}, {{SITE}}, {{VILLE}} {{COULEUR_1}}, {{COULEUR_2}} {{BANNIERE_TEXTE}}, {{BANNIERE_SOUS_TEXTE}} {{BANNIERE_CTA}}, {{BANNIERE_URL}} {{LOGO_URL}} ÉTAPE 3 — Rendu GIF depuis SVG (8-15s) Instancier l'effet choisi (parmi les 55). Appliquer le browser-shim. Boucle 80 frames × deltaTime organique. Encoder GIF qualité max + Floyd-Steinberg. Upload Cloudinary → stocker URL en DB. ÉTAPE 4 — Génération mail de démo (1s) Charger template HTML Gmail simulé. Injecter données client + URL GIF. Auto-générer corps mail selon secteur. Héberger à URL publique unique. ÉTAPE 5 — Génération PDF guide (3s) Charger template PDF 7 pages. Injecter nom, logo, URL personnelle sur chaque page. Générer PDF avec puppeteer headless. ÉTAPE 6 — Génération copier-coller.html (1s) Template HTML avec 3 boutons. Injecter les 3 codes (Gmail / Outlook / HTML universel) avec l'URL Cloudinary du client. ÉTAPE 7 — Création du ZIP (1s) Assembler fichiers 1 à 4 + MON-LIEN-PERMANENT.txt Zipper → stocker → rendre disponible au téléchargement. ÉTAPE 8 — Notification (immédiat) Mettre à jour statut client → LIVRÉ. Afficher résumé avec tous les liens sur le dashboard.
